The Webiny Control Panel is a web-based interface that allows you to manage the license for a particular Webiny instance with the aim of enabling and accessing the premium features. ## Introduction to the Webiny Control Panel

The Webiny Control Panel ("WCP") is a centralized dashboard where you can manage your Webiny licenses and unlock paid features. It provides an easy way to keep track of your Webiny projects and allows you to upgrade or modify your licenses as needed.

WCP is a separate application that is hosted and maintained by the Webiny team. You can access it by visiting <ExternalLink href="https://app.webiny.com/">https://app.webiny.com/</ExternalLink> and logging in with your Webiny account credentials. We'll cover this in more detail later in this chapter.

## When You Need to Use Webiny Control Panel

You only need to use the Webiny Control Panel if you plan to use Webiny's paid features, such as advanced security options, multi-tenancy, premium plugins, or enterprise support. If you are using the free version of Webiny you don't need to access the WCP or manage any licenses.

For this lesson we'll go over the WCP and upgrade our project to the business tier so you can see how the process works and that we can explore some of the paid features.


No credit-card or any payment information will be required at any point during this course.
