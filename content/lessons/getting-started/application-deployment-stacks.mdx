## What are Application Deployment Stacks

In Webiny, an application deployment stack represents a specific configuration of resources and services that make up a Webiny application. Each stack is designed to handle different aspects of the application, such as content management, API services, and front-end delivery. This modular approach allows for better organization, scalability, and management of your Webiny applications.

## Application Deployment Stacks in Webiny

Webiny consists of several predefined application deployment stacks, each serving a specific purpose. The main application deployment stacks in Webiny are:
- **Core Stack**: This stack includes essential services that are required for the Webiny platform to function, such as authentication, persistent storage, and user management.
- **Admin Stack**: This stack is responsible for the Webiny Admin application, which provides the user interface for managing content, settings, and other administrative tasks.
- **API Stack**: This stack handles the GraphQL API services that power the Webiny applications, allowing for data retrieval and manipulation.

### Application Deployment Stacks vs Environments vs Applications

It's important to distinguish between application deployment stacks, environments, and applications in Webiny:
- **Application Deployment Stacks**: These are the infrastructure components that are required to run specific parts of a Webiny application, such as the Admin interface or API services.
- **Environments**: These represent different deployments of your Webiny project, such as development, staging, and production.
- **Applications**: These are applications such as the Headless CMS, Website Builder, File Manager, ect. that run on top of the application deployment stacks.
