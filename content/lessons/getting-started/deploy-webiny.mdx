# Deploy Webiny

<Image src="/learn/images/lessons/getting-started/webiny-deploy.svg" alt="Webiny Deploy" withShadow={false}/>

In this lesson, we will guide you through the process of deploying your Webiny instance to AWS and accessing the admin panel for the first time. By the end of this lesson, you'll have a fully functional Webiny instance running in the cloud, ready for you to start building and managing content.

## Deploying Webiny to AWS

Now that you have your Webiny project set up locally, it's time to deploy it to AWS. To do this, navigate to your project directory in the terminal and run the following command:

<CodeBlock language="shell" filename="Terminal" code={`yarn webiny deploy`} />

This command will deploy your Webiny instance to AWS in the `dev` environment. The deployment process may take a few minutes, as it involves setting up various AWS services and resources. Once the deployment is complete, you will see a success message in the terminal along with the URL to access your Webiny admin panel. On the first deployment, the CLI also opens the admin panel in your browser so you can finalize the setup.

<Callout type="info" title="Deployment Time">
    The deployment time can vary depending on your internet connection and AWS service availability. The first deployment typically takes up to 10 minutes.
    Please be patient and avoid interrupting the process.
    Deploying for the first time may take longer as AWS provisions all necessary resources. Subsequent deployments will be much faster.
</Callout>

## Accessing the Webiny Admin Panel

Once the deployment is complete, you can access the Webiny admin panel using the URL provided in the terminal output. Open your web browser and navigate to that URL. Since this is your first time accessing the admin panel, you will see the installation wizard, where you provide a few project details and create an admin user account.

<Callout type="info" title="Admin Panel URL">
    If you missed the URL in the terminal output, you can find it by running the following command in your project directory:
    `yarn webiny info`
</Callout>

<Image src="/learn/images/lessons/getting-started/installation-wizard.png" title="Webiny Admin - Installation wizard"/>

Click "Let's get started", then fill in the "Basic info" step (project name, organization name, where you heard about Webiny, and accepting the Terms of Service) and the "Admin account" step (first name, last name, email address, and password), clicking "Next step" after each. The wizard then installs Webiny. When it finishes, click "Start using Webiny".

Once the installation wizard is complete, sign in with the admin account you just created and you will land on the Webiny admin dashboard. Congratulations! You have successfully deployed Webiny to AWS and accessed the admin panel for the first time.

<Image src="/learn/images/lessons/getting-started/webiny-admin-dashboard.png" title="Webiny Admin - Dashboard"/>

At this point we have a Webiny Community edition instance deployed and ready to use.
