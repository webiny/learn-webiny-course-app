# Parts that make Webiny

Webiny is a comprehensive content platform that consists of several key components, each designed to handle specific aspects of content management and application development. In this lesson, we will explore the main parts that make up Webiny and how they work together to provide a seamless experience for both developers and content editors.

## Core Components of Webiny

Webiny is built on a foundation of several core components that work together to provide a robust and flexible content platform. Unlike many other platforms that are monolithic in nature, Webiny is designed from the ground up to be modular and extensible so that it can support even the most complex projects and use-cases. Developers can modify Webiny's functionality as needed in a maintainable and upgradable way, so things don't break between updates.

<Image src="/images/lessons/foundation/webiny-layers.png" title="Parts that make Webiny" />


The core components that make up Webiny include:
- **Applications**: Webiny comes with a set of applications that cater to different content management needs, such as the Headless CMS, Website Builder, File Manager, Publishing Workflows, and a few more.
- **Webiny Framework**: This is the underlying framework that powers Webiny. It is your gateway to building custom applications on top of Webiny, and customizing the existing ones, including both the UI and the API.
- **Infrastructure as Code (IaC)**: Webiny uses Infrastructure as Code principles to define and manage its cloud infrastructure. This allows for easy deployment, scaling, and management of resources in a consistent manner.

## Webiny's Architecture

Webiny's architecture is designed to be modular and scalable, allowing developers to build and deploy applications quickly and efficiently. The architecture consists of several layers, each responsible for different aspects of the platform.

The main layers of Webiny's architecture include:
- **Client Layer**: This layer includes the Webiny Admin application, which provides a user-friendly interface for content editors and administrators to manage content and configure the platform.
- **Application Layer**: This layer consists of the various Webiny applications that handle specific content management tasks, such as the Headless CMS and Website Builder.
- **Framework Layer**: This layer includes the Webiny Framework, which provides the tools and libraries needed to build custom applications and extend existing ones.
- **Infrastructure Layer**: This layer is responsible for managing the cloud infrastructure using Infrastructure as Code principles, ensuring that resources are deployed and managed consistently.
